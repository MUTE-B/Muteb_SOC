# MUTEB SOC Interview Presentation


## Project Introduction


MUTEB SOC is a defensive Security Operations Center simulation platform that I developed to practice real SOC Analyst workflows.


The project focuses on monitoring, detection, investigation and incident response.



## Architecture Explanation


The workflow:


1. Security events are generated from systems.

2. Logs are collected.

3. SIEM engine analyzes events.

4. Detection rules generate alerts.

5. Analyst investigates incidents.

6. Reports are created.



## Detection Example


Example:

SSH Brute Force Detection


Process:


- Authentication logs analyzed.
- Multiple failed attempts identified.
- Alert generated.
- Incident case created.
- Investigation report produced.
