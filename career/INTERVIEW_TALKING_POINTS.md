# SOC Interview Talking Points


## Explain MUTEB SOC


MUTEB SOC is a defensive security project I built to simulate SOC analyst operations.


## Detection Example


I created detection logic for SSH brute force attacks by analyzing authentication logs and mapping the behavior to MITRE ATT&CK T1110.


## Investigation Process


My workflow:

1. Detect alert

2. Validate event

3. Collect evidence

4. Analyze indicators

5. Create incident report

6. Improve detection rules
