## Project Overview

Muteb SOC is a modular Linux security monitoring framework designed to automate routine system inspection tasks commonly performed by SOC analysts and Linux administrators.

The framework focuses on:

- System Monitoring
- Service Monitoring
- Network Monitoring
- User Monitoring
- Security Baseline
- Incident Reporting
- Daily Health Check
- Log Collection
