# Muteb SOC Architecture

## Overview

Muteb SOC is a modular Blue Team and SOC laboratory designed for learning, automation, incident response, log analysis and defensive security.

## Core Components

- Bash Automation
- Python Automation
- Detection Rules
- Incident Response Playbooks
