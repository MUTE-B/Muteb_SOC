# Detection Rules

## Overview

Detection rules identify suspicious security events.

## Available Rules

- SSH Brute Force
- Privilege Escalation
- Suspicious Login
- Reverse Shell
- Web Attack
- Malware Execution


## Framework

Rules are based on:

- MITRE ATT&CK
- Sigma Rule concepts
- SOC Detection Engineering
