# Bash Automation Guide

## Overview

Bash scripts are used for system administration and security automation.

## Included Tools

- log_collector.sh
- package_audit.sh
- firewall_status.sh
- ssh_audit.sh
- update_checker.sh
- backup_restore.sh


## Usage

Make files executable:

chmod +x automation/bash/*.sh


Run script:

./script_name.sh


## Security Purpose

- Collect logs.
- Audit packages.
- Check firewall.
- Review SSH configuration.
- Backup important files.
