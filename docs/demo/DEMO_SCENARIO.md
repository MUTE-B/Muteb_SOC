## Scenario 1: SSH Brute Force Detection


### Attack Simulation

### Detection

- Authentication failures
- Suspicious source IP
- Repeated usernames


### Investigation

SOC Analyst:

1. Reviews logs.

2. Identifies indicators.

3. Creates incident case.

4. Generates report.
