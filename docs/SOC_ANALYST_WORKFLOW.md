# SOC Analyst Workflow - MUTEB SOC


## Phase 1 - Detection

Sources:

- Linux Logs
- Authentication Events
- Network Events
- File Events


## Phase 2 - Triage

Analyst Actions:

- Validate alert
- Determine severity
- Identify affected host
- Collect indicators


## Phase 3 - Investigation

Activities:

- Log analysis
- Process inspection
- Network analysis
- IOC investigation


## Phase 4 - Containment

Actions:

- Block indicators
- Isolate affected systems
- Disable compromised accounts


## Phase 5 - Recovery

Actions:

- Remove threats
- Restore services
- Verify security controls


## Phase 6 - Lessons Learned

Documentation:

- Incident report
- Detection improvement
- Rule updates
