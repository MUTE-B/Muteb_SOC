# MUTEB SOC Wazuh Integration

## Purpose

Integration guide for forwarding security events to Wazuh SIEM.

## Collected Data

- Authentication Logs
- SSH Events
- Firewall Events
- System Events
- Threat Hunting Results

## Log Sources

/var/log/auth.log
/var/log/syslog
/var/log/ufw.log

## Detection Coverage

- SSH Brute Force
- Suspicious Login
- Privilege Escalation
- Malware Indicators
