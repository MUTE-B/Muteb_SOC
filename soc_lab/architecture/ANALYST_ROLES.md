# SOC Analyst Roles


# Tier 1 Analyst


Responsibilities:

- Monitor alerts
- Validate incidents
- Perform initial triage
- Escalate suspicious activity



# Tier 2 Analyst


Responsibilities:

- Deep investigation
- Malware analysis
- Threat hunting
- Root cause analysis



# Threat Hunter


Responsibilities:

- Search for hidden threats
- Analyze indicators
- Develop hypotheses



# Detection Engineer


Responsibilities:

- Create Sigma rules
- Improve detections
- Map techniques to MITRE ATT&CK



# Incident Responder


Responsibilities:

- Containment
- Evidence collection
- Recovery actions
