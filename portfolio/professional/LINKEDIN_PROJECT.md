

# MUTEB SOC Enterprise

Designed and developed MUTEB SOC Enterprise, a defensive cybersecurity platform simulating enterprise Security Operations Center workflows.

- Threat Intelligence

- SOAR Automation

- IOC Management

- Compliance Monitoring

- Security Reporting


Technical Stack:


- Python

- Flask

- REST APIs

- JWT Authentication

- RBAC

- Docker


Focus:


Blue Team Operations | SOC Analyst Workflow | Defensive Security Engineering
