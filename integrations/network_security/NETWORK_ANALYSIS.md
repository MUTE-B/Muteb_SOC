# MUTEB SOC - Network Security Analysis


## Overview

Network monitoring is a key SOC capability used to identify suspicious communication and potential threats.



## Network Monitoring Areas


### Traffic Analysis

Monitor:

- Source IP
- Destination IP
- Ports
- Protocols
- Communication patterns



### Common Security Ports


| Port | Service |
|---|---|
|22|SSH|
|53|DNS|
|80|HTTP|
|443|HTTPS|
|3389|RDP|



## Investigation Process


1. Identify suspicious connection.

2. Analyze source and destination.

3. Check reputation of indicators.

4. Map activity to MITRE ATT&CK.

5. Create incident report.
