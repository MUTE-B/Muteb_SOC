# Wireshark Analysis Workflow


## Purpose

Analyze network packets for security investigation.



## SOC Workflow


### Step 1

Capture traffic.



### Step 2

Filter suspicious communication.



Examples:


http

dns

tcp

ssh




### Step 3

Investigate:


- Source address
- Destination address
- Packet behavior
- Protocol usage



### Step 4

Document findings.



## Analyst Skills


- Packet Analysis
- Network Investigation
- Threat Detection
