# Contributing Guide


شكراً للمساهمة في تطوير المشروع.



## Contribution Steps


1. Fork the project.


2. Create a new branch.


3. Make changes.


4. Test your changes.


5. Submit Pull Request.



## Guidelines


- Write clean code.

- Add documentation.

- Explain changes.

- Follow security practices.
